# 🛒 Full Stack E-Commerce Web Application

This is a full-stack e-commerce web application built with **React (Vite)** on the frontend and **Express.js + MongoDB** on the backend. It supports user authentication, product listings, cart and checkout functionality, as well as an admin dashboard for managing products and orders.

---

## 🚀 Features

### 👥 User Features
- User registration and login using JWT
- View products with details like price, image, and description
- Search and filter products by name,category and price
- Add to cart, remove from cart, and update quantities
- Checkout with razorpay payemnt and shipping address
- user account and address management
- Order history (authenticated users only)

### 🛠️ Admin Features
- Admin-only access to manage products and orders
- Create, update, delete products
- View all orders and update their statuses 

---

## ⚙️ Tech Stack

### Frontend
- React (Vite)
- React Router
- Axios
- Context API
- Tailwind CSS 
- LocalStorage for persistent auth/cart

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JSON Web Token (JWT)
- Bcrypt for password hashing
